🎉 RetroFeedback - Event Feedback System
What it does:

A fully functional web application where event organizers can collect, manage, and analyze feedback from participants.

Key Features:

🔐 User Authentication - Simple username login
🎯 Create Rooms - Organizers generate unique room codes to host events
🚪 Join Rooms - Participants use room codes to join feedback sessions
⭐ Interactive Feedback - Rate events (1-5 stars) and provide detailed comments with categories
📊 Live Analytics - Real-time feedback statistics with:
Average ratings
Feedback distribution charts
Rating breakdowns
📥 PDF Export - Download professional feedback reports with ratings, comments, and statistics in table format
💾 Full CRUD - Create rooms, read/view feedback, update data, delete rooms
🎨 Retro Neon UI - Classic 80s/90s aesthetic with vibrant cyan, magenta, and yellow colors
📱 Fully Responsive - Works seamlessly on mobile, tablet, and desktop devices
How it works:

User logs in with username
Choose to Create Room (organizer) or Join Room (participant)
Organizer gets shareable room code; participants submit feedback
View analytics dashboard with charts, statistics, and all responses
Export complete feedback report as PDF
Tech Stack: Pure HTML/CSS/JavaScript with localStorage (no backend needed)
